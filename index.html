Customer & Photos

Upload the customer's cat photos. More angles = more accurate color placement. Front and at least one side are recommended minimum.

AI Photo Analysis

This calls the Claude API directly from your browser using your own API key (never sent anywhere else, kept in memory for this session only — check "remember" to also save it in this browser's local storage). The AI's only job is to look at the photos and describe coat colors and markings using your yarn palette — it never touches stitch counts or construction.

Marking Report

Structured result from the AI. You can hand-edit this JSON before applying it to the stitch maps — nothing here touches stitch counts, only which colors get suggested where.

Talk to the AI

Once you've run an analysis, tell it what to fix in plain language — it keeps the photos in mind and revises the marking report above. Examples: "the belly is more cream than white," "there's a dark patch on the left ear you missed," "make the tail solid ginger, no tip." Each reply updates the Marking Report textarea above — click "Paint Stitch Maps From Report" again to push the change into the grids.

Paint Stitch Maps

Every stitch already exists in the base pattern — the AI (and you) only ever assign a color to a square. Click a swatch below, then click, drag-paint, or bucket-fill squares. Internally every square has a permanent ID like HEAD-R08-S14 (you never need to see these — it's just how the software keeps the pattern and the picture in sync).

Live Preview

Approximate preview only, built from the same colored squares you just painted. Each round is a true ring: its circumference comes from that round's real stitch count, so the pattern's own numbers define the shape — no separate 3D model to keep in sync. Self-contained, no internet needed to view. Drag to rotate, scroll to zoom.
